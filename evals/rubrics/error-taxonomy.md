# Error taxonomy

| Code | Meaning |
| --- | --- |
| `invalid_evidence` | Citation references a missing segment |
| `empty_evidence` | Claim stored without evidence |
| `unexpected_html` | Model returned HTML |
| `not_found_expected` | Q&A should abstain but answered |
| `supported_expected` | Q&A should answer but abstained |
| `quota_exceeded` | User hit a configured limit |
| `storage_error` | Audio object missing or unreachable |
